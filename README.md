## ПРОБЛЕМА, КОТОРУЮ МЫ РЕШАЕМ

В современном образовании есть фундаментальный разрыв. И нет, это не преувеличение — это стратегический просчёт, на который указывают десятилетия исследований когнитивной науки.

**Вот что показывают данные:**

| Метрика | Данные |
|---------|--------|
| Забывается за 24 часа | **50-80%** информации |
| Забывается за неделю | **90%** материала |
| Dropout пользователей Anki | **70-80%** — люди просто бросают |
| Ручное создание карты знаний | **20 минут** — слишком долго для эффективного обучения |

Существующие инструменты работают разрозненно. Каждый хорош в своём, но вместе они не дают целостной картины.

**Anki** даёт память, но оставляет знания фрагментированными.

**Ментальные карты** дают структуру, но не решают забывание.

**LLM** генерируют контент, но не строят систему обучения.

**Miya объединяет все три подхода в единую экосистему.**

## НАША ЦЕЛЬ

Мы создаём не просто инструмент для запоминания, не очередной клон Anki и не магический add-on для Obsidian. Мы строим **интерактивную платформу знаний**, где каждая вершина — это факт, каждое ребро — связь между фактами, а вся карта — это полное, структурированное понимание предмета.

### Три столпа нашей платформы:

1. **Система интервального повторения (SM-2)** — повторяешь материал именно тогда, когда мозг готов его забыть
2. **Ментальные карты (граф знаний)** — видишь всю структуру целиком, не теряя связи между фактами
3. **AI-генерация** — превращаешь текст в структурированную карту за 3 секунды

## ЧТО НОВОГО В ЭТОМ ОБНОВЛЕНИИ

### 1. AI-генерация ментальных карт — новый инструмент создания

Загружаешь PDF/DOCX/TXT. Нажимаешь **"Сущность"**. Через **3 секунды** — готовая ментальная карта.

*Раньше это занимало 20 минут.*

Модель (GPT-4o через ProxyAPI) выделяет:
- Ключевые концепции (сущности)
- Связи между ними
- Иерархическую структуру

*Результат:* **F1-score ~0.78**, precision ~0.79, recall ~0.78 

**В 400 раз быстрее с сохранением 80% точности.** Идеальный баланс между скоростью и качеством.

### 2. Режим изучения ветвей — обучение по структуре

Нажимаешь любую вершину на карте → система запускает карточки **только по этой ветке знаний**.

Ты выбираешь, какой раздел материала укреплять — и концентрируешь усилия именно там.

Система сама подсказывает: *"Вот эти карты уже пора повторить. Учить всё дерево или только просроченное?"*

### 3. Радиальная раскладка — визуальная ясность

Алгоритм размещает корневую вершину в **центре** карты, а дочерние ветви — радиально во все стороны.

Это и красиво, и **информативно**: видно, как одна концепция порождает другую, где основные идеи, где — детали и уточнения.

## ЦИФРЫ

Сравнение ручной разметки vs AI-генерации на 5 текстах:

| Текст | Ручная карта (минуты) | AI-карта (секунды) | Precision | Recall | F1 |
|-------|----------------------|-------------------|-----------|--------|-----|
| Технический реферат | 18 | 3 | 0.82 | 0.71 | **0.76** |
| Учебный параграф | 25 | 4 | 0.79 | 0.85 | **0.81** |
| Научная статья | 22 | 3 | 0.75 | 0.78 | **0.76** |
| Инструкция | 15 | 3 | 0.84 | 0.74 | **0.79** |
| Конспект лекций | 20 | 3 | 0.77 | 0.81 | **0.79** |

**Среднее значение:** ручная карта = **20 минут**, AI = **3 секунды**. Precision 0.79, Recall 0.78, F1 **0.78**.

**Вывод:** AI достаточно точен, чтобы доверять ему черновик карты. Человек нужен только для финальной шлифовки.

## ТЕХНОЛОГИИ

| Слой | Технология | Назначение |
|------|------------|------------|
| **Frontend** | React + TypeScript + Vite | Интерфейс и визуализация |
| **Frontend UI** | SVG + foreignObject | Карта с переносом текста |
| **Backend** | FastAPI + SQLAlchemy | Серверная логика |
| **Database** | PostgreSQL | Хранение данных |

| **Auth** | JWT | Авторизация |

## БЫСТРЫЙ СТАРТ

### Требования
- Node.js 18+
- Python 3.10+
- PostgreSQL 15+

### 1. Клонируй репозиторий
```bash
git clone https://github.com/ex-alander/Miya.git
cd Miya
```

### 2. Запусти бэкенд
```bash
cd backend
cp .env.example .env
# Добавь PROXY_API_KEY или GROQ_API_KEY в .env
alembic upgrade head
uvicorn app.main:app --reload
```

### 3. Запусти фронтенд
```bash
cd frontend
npm install
npm run dev
```

### 4. Открой приложение
```
http://localhost:5173/battlefield
```

### 5. Создай первую карту
Кликни **"+" → "AI generation"** → загрузи документ → нажми **"Сущность"** → наблюдай, как строится твоя первая ментальная карта.
