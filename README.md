## Проблема

Человеческий мозг устроен так, что 80% новой информации забывается в течение 24 часов, а 90% — в течение недели. Эта кривая забывания не зависит от интеллекта или мотивации. Это биологический закон.

Существующие инструменты для обучения работают по отдельности. Anki решает проблему забывания через интервальное повторение, но превращает знания в набор изолированных фактов. Ментальные карты дают структуру и показывают связи, но не помогают их удерживать. LLM генерируют карты за секунды, но не превращают их в систему обучения.

Каждый инструмент закрывает одну часть проблемы. Ни один не решает её целиком.

| Метрика | Данные |
|---------|--------|
| Забывается за 24 часа | **50-80%** информации |
| Забывается за неделю | **90%** материала |
| Dropout Anki | **70-80%** пользователей |
| Ручная ментальная карта | **20 минут** |

---

## Решение

Miya объединяет три подхода в единой системе. Алгоритм SM-2 управляет повторением в момент готовности забыть. Радиальный граф визуализирует связи между концепциями. AI-генерация создаёт карту из текста за минуту.

Пользователь загружает текст — получает готовую ментальную карту с иерархией узлов и описаниями. Клик по ветке запускает режим изучения с карточками, которые планируются по кривой забывания. Система работает как единое целое: структура питает память, память закрепляет структуру.

| Компонент | Технология | Что даёт |
|-----------|------------|----------|
| Интервальное повторение | SM-2 алгоритм | Повторение в момент готовности забыть |
| Ментальные карты | Кастомный граф + радиальная раскладка | Визуализация связей между фактами |
| AI-генерация | RAG + GPT-4o | Карта из текста за 51–72 секунды |

## Результаты экспериментов

Мы провели три эксперимента с 12 участниками в каждой группе.

**AI vs Human.** Человек тратит 20 минут на ручное создание карты. RAG+GPT генерирует карту за 72 секунды при F1 0.80 и удержании 69% через неделю. Эффективность (удержание / время) у RAG+GPT — 57 против 3 у человека, что в 19 раз выше. Влияние RAG растёт с длиной текста: на длинных текстах разница достигает +0.19 F1.

**SRS vs No SRS vs Anki.** Без повторения удержание падает до 16% через месяц. С SM-2 в Miya — 61%. С SM-2 в Anki — 67%. Разница между Miya и Anki статистически незначима (p > 0.05). Скорость забывания в Miya — 0.80% в день, в Anki — 0.67%, без повторения — 2.36%. Miya обеспечивает такое же удержание, как Anki, добавляя визуальную структуру и AI-генерацию.

**Mind Maps vs No Mind Maps.** В группе с ментальной картой соотношение понимания связей к фактам составляет 0.96 сразу и 0.93 через неделю. В группе с линейным текстом — 0.61 и 0.58. Разница — 57–60% в пользу ментальных карт. Фактическая память в группе с картами выше через неделю (65.9% против 59.1%). Ментальные карты не ухудшают запоминание фактов в долгосрочной перспективе и значительно улучшают понимание связей.

| Эксперимент | Метрика | Miya | Контроль | Результат |
|---|---|---|---|---|
| AI vs Human | Эффективность | 57 | 3 | в 19 раз выше |
| RAG impact | F1 на длинных текстах | 0.82 | 0.63 | +0.19 |
| SRS vs No SRS | Удержание через 1 месяц | 61% | 16% | +45 п.п. |
| Miya vs Anki | Удержание через 1 месяц | 61% | 67% | эквивалентны |
| Mind Maps vs Text | Связи / Факты (ratio) | 0.93 | 0.58 | +60% |

## Архитектура

Бэкенд построен на асинхронном FastAPI с слоем персистентности на PostgreSQL. Миграции управляются через Alembic. Аутентификация — JWT. Все зависимости упакованы в Docker.

Фронтенд написан на React с TypeScript. Визуализация ментальной карты — радиальный Tidy Tree, реализованный через кастомный SVG-рендеринг. Каждый узел интерактивен: клик открывает детали, перетаскивание меняет иерархию, изучение ветки запускает SM-2 сессию.

AI-слой построен на RAG-пайплайне. Текст нарезается на чанки, индексируется через FAISS и BM25, затем подаётся в LLM с промптом для извлечения иерархической структуры. Вся система оркестрируется через Docker Compose и деплоится через GitHub Actions.

## Быстрый старт

### Требования
- Node.js 18+
- Python 3.10+
- PostgreSQL 15+
- Docker (опционально)

### Запуск с Docker

```bash
git clone https://github.com/ex-alander/Miya.git
cd Miya
cp backend/.env.example backend/.env
# Добавь PROXY_API_KEY или GROQ_API_KEY в backend/.env
docker-compose up --build
```

### Или вручную

**Backend:**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # venv\Scripts\activate на Windows
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

Открой `http://localhost:5173/battlefield`

## Возможности

**AI-генерация ментальных карт из текста.** Загрузи PDF/DOCX/TXT — система выделяет ключевые концепции и связи, строит радиальный граф. Fallback на Groq при недоступности основной API.

**Режим изучения ветвей.** Клик по вершине запускает карточки только по этой теме. Система подсказывает: повторить сейчас или позже.

**Радиальная раскладка графа.** Корневая вершина в центре, ветви радиально. Кастомный алгоритм без внешних библиотек. Визуальная иерархия: размер узлов и толщина связей зависят от глубины.

**Система интервального повторения (SM-2).** Карточки автоматически планируются по кривой забывания. Поддержка изображений и LaTeX.
