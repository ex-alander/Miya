# Fonts for PDF export (Cyrillic / Unicode)

For PDF export to display Cyrillic and other non-Latin characters correctly, add these font files here:

- **DejaVuSans.ttf**
- **DejaVuSans-Bold.ttf**

Download from: https://dejavu-fonts.github.io/ (Releases → ttf zip)

Place the `.ttf` files in this directory. If the fonts are not found, PDF export will fall back to Helvetica (Latin-only; other characters may appear as squares).
